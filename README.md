# sliceepoch

Slice encode/decode helpers for epoch payloads in pipelines.

**Site:** https://theworker02.github.io/sliceepoch/

## Install / run

```bash
git clone https://github.com/theworker02/sliceepoch.git
cd sliceepoch
node src/cli.js
node --test
```
